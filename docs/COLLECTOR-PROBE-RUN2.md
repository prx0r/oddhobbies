## The Collector Thesis

> **People spend £50-£500+ acquiring something they love. OddHobb sells the £15-£35 object that makes that thing look like it deserves £500.**

Don't manufacture the collectible. Manufacture its **stage**.

## The "OddHobb Museum" System

**One parametric kernel → infinite collector markets:**

```
Object adapter → Plaque slot → Optional magnet → Optional LED → Decorative shell
```

| Object | Adapter | Shell Theme |
|--------|---------|-------------|
| TCG card | Card slot (63.5x88mm) | Gothic arch |
| Coin | Capsule mount (30-40mm) | Museum marble |
| Artisan keycap | MX stem socket | Celestial |
| Die | Dice cup (25mm) | Wizard tower |
| Miniature | Plinth (25-60mm) | Ruined temple |
| Fountain pen | Pen cradle | Japanese garden |
| Retro cartridge | Cartridge slot | Arcade cabinet |
| Comic | Slab/raw adapter | Gallery frame |

**Meshy shells:** Gothic, brutalist, classical, celestial, botanical, Japanese, art-deco, fantasy ruin.

**Plaque generator:** Name, date, provenance, location, story.

## IP Safety Rules

| Don't | Do |
|-------|-----|
| Use "The Witcher" in titles | "Fantasy medieval map frame" |
| Copy game artwork | Original designs that fit the aesthetic |
| Reproduce franchise characters | Generic themed shells (gothic, space, nature) |
| Use trademarked game logos | "Fits standard card sizes" not "Pokemon-compatible" |

**Safe approach:** Sell the infrastructure around the fandom, not the fandom itself.
