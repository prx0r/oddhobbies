## The Flywheel

```
Folklore video → viewer falls asleep → wakes up → wants more
→ subscribes to channel → buys CD → buys eBook → buys print
→ tells friends → friends watch video → repeat
```

Each product advertises the videos. Each video advertises the products. One niche, complete stack.
