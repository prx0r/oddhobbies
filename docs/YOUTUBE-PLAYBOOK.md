# OddHobb YouTube Playbook

> 3 channels. Every video is an ad for OddHobb. Logo at start, product link at end.

---

## The Playbook

```
1. Interesting content about a niche/hobby
2. OddHobb logo animation (2 seconds)
3. Video body (educational, story, or ambient)
4. "This video inspired by our [product] at OddHobb"
5. Product link in description + pinned comment
6. End screen: subscribe + product link
```

**Every video = content + soft sell. Never hard sell.**

## The OddHobb Logo

### Logo Animation (2 seconds)
```
Frame 1: Black screen
Frame 2: "OddHobb" wordmark fades in (clean sans-serif)
Frame 3: Small icon appears (question mark, star, or abstract shape)
Frame 4: Tagline "For people who are really into things" fades in
Frame 5: Hold for 0.5s
Frame 6: Cut to video content
```

### Where to Put Logo
- **Start:** 2-second animation (every video)
- **End:** Still image on end screen
- **Thumbnail:** Small logo in corner
- **Description:** Link to OddHobb.com

### Logo Files Needed
- [ ] PNG (transparent) for thumbnails
- [ ] MP4 animation (2 seconds) for video intro
- [ ] SVG (vector) for website
- [ ] Banner images for each YouTube channel

## Content Production Pipeline

### Per Video (30-60 minutes)
1. Pick topic from list
2. Write script (reuse sleepvids templates)
3. Record voiceover (or use TTS)
4. Create visuals (or use stock)
5. Edit with OddHobb logo intro + product outro
6. Upload to YouTube with description + tags
7. Pin comment with product link
8. Share on social media

### Weekly Schedule
| Day | Channel | Video | Product Featured |
|-----|---------|-------|------------------|
| Monday | Odd Sleep | Sleep story | Dream journal |
| Wednesday | Odd Minds | Explainer | Neurodivergent tools |
| Friday | Odd Stories | Human story | Personalized gifts |

**3 videos per week × 4 weeks = 12 videos/month**
**Each video = 1 product ad = traffic to Etsy**
