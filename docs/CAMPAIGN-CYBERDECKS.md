## What Is a Cyberdeck

A DIY personal computer built in the cyberpunk aesthetic. Originated in Gibson's *Neuromancer* (1984). Real-world: Raspberry Pi + 3D-printed case + mechanical keyboard + small display. The 2026 twist: young women building "girly" cyberdecks — mermaid shells, Hello Kitty purses, pink aesthetics — rejecting Silicon Valley homogeneity.

## Tutorial Production Pipeline

```
1. Write tutorial script (IKEA-style, step-by-step)
2. Generate visuals (Agnes Video Generator or screen recording)
3. Add TTS narration (Agnes built-in or edge_tts)
4. Add OddHobb logo intro + product outro
5. Upload to YouTube
6. Link to Etsy products in description
```

**Agnes Video Generator** (free, open-source):
- Text → multi-scene video
- Built-in TTS narration
- Auto subtitles
- No GPU needed
- No watermark
- MIT license
