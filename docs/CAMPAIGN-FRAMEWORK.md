# Campaign Framework

> Each campaign = supplier → products → videos. Work backwards from demand.

---

## The Formula

```
1. DEMAND: What are people searching for? (Pinterest, Etsy, Reddit)
2. PRODUCTS: What do they need? (3D print, digital, physical media)
3. SUPPLIERS: Who makes it? (Makr3D, Kunaki, Prodigi, self-fulfilled)
4. VIDEOS: What content advertises it? (Sleepy documentaries)
5. DISTRIBUTION: Where does it go? (YouTube, Spotify, Etsy, Amazon)
```
