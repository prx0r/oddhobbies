# OddHobbies Brand Guide

## Voice & Tone

### We Sound Like
- A hobbyist who found a better way
- Practical, not precious
- "This fits X" not "revolutionary"
- "Designed to solve Y" not "game-changing"

### We Never Sound Like
- Corporate
- Medical/therapeutic
- Condescending ("even beginners can...")
- Generic ("high quality, great value")

## Naming

### Format
`[Product] — [What It Fixes]`

### Examples
- "Magnetic Needle Minder — Swappable Sculpted Toppers"
- "Floss Drop Set — House-Shaped with ID Slots"
- "Diamond Painting Tray Tower — Holds 12 Trays"

### Avoid in Titles
- Brand names (Scrabble, Rummikub, DMC, Diamond Art Club)
- Medical language
- Superlatives ("best", "ultimate", "perfect")

### Use in Titles
- Dimensions ("fits tiles up to 15mm")
- Compatibility ("fits standard 6-strand floss")
- Quantity ("set of 10", "3-pack")

## Visual Identity

### Colors
| Color | Hex | Use |
|-------|-----|-----|
| Warm White | #FAF8F5 | Backgrounds |
| Charcoal | #2C2C2C | Text |
| Terracotta | #C4654A | Accents |
| Sage | #7A9E7E | Secondary accent |
| Kraft | #C9B99A | Containers, tags |

### Typography
- **Headings:** DM Sans (clean, modern)
- **Body:** Inter (readable)
- **Accents:** Caveat (hand-drawn feel)

### Photography Style
- Product on clean surface (wood, linen, kraft paper)
- Hands holding/using the product (scale reference)
- No busy backgrounds
- Natural light preferred

## Listing Template

### Title
`[Product] — [Fix] | [Audience] | [Format]`

### Example
`Magnetic Needle Minder — Swappable 3D Topper | Cross Stitch Accessory | Personalized Gift`

### Description
```
[1 sentence: what this is and what problem it solves]

[2-3 sentences: how it works and why it's different]

WHAT'S INCLUDED:
• [item 1]
• [item 2]

SPECIFICATIONS:
• [material]
• [size]
• [compatibility]

NOTE: [Any usage notes, care instructions, etc.]

Designed and printed by a fellow hobbyist. Every piece is original.
```
