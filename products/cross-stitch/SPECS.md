## 1. Modular Needle Minder — Swappable Sculpted Toppers

### The Problem
Standard needle minders are flat metal clips or basic enamel pins. They work, but they're boring and you're stuck with whatever design you bought. Hobbyists want variety but don't want 50 separate minders cluttering their setup.

### The Fix
A magnetic base system with swappable sculpted toppers. Buy one base, collect toppers. Each topper snaps on magnetically. Store unused toppers on a display strip.

### Specifications

**Base:**
| Field | Value |
|-------|-------|
| Material | PLA+ (base) + neodymium magnets (2x N52 10mm disc) |
| Size | 30mm diameter, 4mm thick |
| Magnet strength | Holds 15+ layers of fabric |
| Color | Black, white, kraft brown (3 options) |
| Backing | Felt pad to protect fabric |

**Toppers:**
| Field | Value |
|-------|-------|
| Material | PLA+ (standard) or resin (detailed) |
| Size | 25mm diameter, 3-5mm thick |
| Attachment | Magnetic snap (no tools needed) |
| Collection | Start with 6 designs, expand monthly |

### Launch Collection — 6 Toppers

### Meshy Prompts (for topper generation)

**General structure:**
```
A tiny 3D sculpted [subject], circular format, 25mm diameter, flat back with magnetic attachment point. Simplified, clean details suitable for 3D printing at small scale. No overhangs longer than 2mm. [Style: cute/minimal/detailed].
```

**Example — Cat Nap:**
```
A tiny 3D sculpted sleeping cat curled in a ball, circular format, 25mm diameter, flat back with magnetic attachment point. Simplified, cozy details. Clean topology for FDM 3D printing at 0.12mm layer height. No overhangs longer than 2mm. Cute, minimal style.
```

### Print Settings (FDM)
- Layer height: 0.12mm (for detail)
- Infill: 100% (solid, weight feels premium)
- Material: PLA+ (easy to print, good detail)
- Supports: none needed (flat back design)
- Time: ~15-25 min per topper
- Cost: ~$0.15-0.30 material per topper

## 2. Floss Drop Set — House-Shaped with ID Slots

### The Problem
Standard floss drops are plain plastic tags with a hole. You write the DMC number on a sticker that falls off. When you organize 200+ colors, finding the one you need is a scavenger hunt.

### The Fix
House-shaped floss drops with a built-in label slot (fits a small paper insert with the color code). Shaped like tiny houses so they look cute on a ring or in a organizer. Each house has a different roof style so you can sort by color family.

### Specifications

| Field | Value |
|-------|-------|
| Material | PLA+ |
| Size | 30mm tall x 20mm wide |
| Hole | 5mm (fits standard floss rings) |
| Label slot | 15mm x 5mm (fits paper insert) |
| Roof styles | 4 types (pitched, flat, dome, pointed) |
| Colors | 6 base colors (sort by color family) |

### Roof-to-Color Family Mapping
| Roof | Color Family | Base Color |
|------|-------------|------------|
| Pitched | Reds/Pinks | Terracotta |
| Flat | Blues/Purples | Blue |
| Dome | Greens/Yellows | Green |
| Pointed | Browns/Neutrals | Brown |
| Round | Oranges/Golds | Orange |
| No roof | Whites/Grays | White |

### Pricing
- Set of 10 (mixed roofs): $12.99
- Set of 20 (all roofs): $22.99
- Set of 50 (full collection): $49.99
- Ring + 10 drops: $14.99

### Print Settings
- Layer height: 0.16mm
- Infill: 80%
- Material: PLA+
- Supports: none
- Time: ~8-12 min per drop
- Cost: ~$0.08-0.12 per drop
