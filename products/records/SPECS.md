# OddHobb Records

> Physical sleepy albums. YouTube audio → Spotify → CD on Etsy → Amazon ebook.
> Kunaki for cheap manufacturing. DiskCrafters for UK premium. WALRUS for micro-label feel.

---

## The Flow

```
YouTube video (1-3 hour sleepy documentary)
  ↓ extract audio
Spotify / Apple Music (publish album)
  ↓ physical product
Kunaki CD ($2) → Etsy listing ($15-19)
  ↓ companion product
Amazon ebook (liner notes + extended text)
  ↓ cross-promotion
YouTube description links to Etsy
Etsy listing links to YouTube
```

## Content → Product Flow

```
1. Write script for "Sleepy Watchmaking" (2 hours)
2. Record voiceover (calm, warm, 0.7x pace)
3. Create 8 × 8-min tracks from the audio
4. Upload to YouTube (full 2-hour video)
5. Upload to Spotify/Apple Music (album)
6. Send to Kunaki (CD manufacturing)
7. List CD on Etsy ($14.99)
8. Write Amazon ebook (liner notes + extended text)
9. YouTube description links to Etsy CD
10. Etsy listing links to YouTube video
```

## ElevenLabs for Fairy Tales

For Folk & Fable / fairy tale content, ElevenLabs TTS can create professional narration:

| Voice Style | Use For |
|-------------|---------|
| Warm, mature storyteller | Fairy tales, folklore |
| Calm, wise narrator | Mythology, history |
| Gentle, soft voice | Bedtime stories |
| Slightly dramatic | Folk tales with tension |

**Cost:** ElevenLabs free tier = 10,000 chars/month. Paid = $5-22/month.

**For 8 × 8-min tracks = ~64 min audio = ~15,000 words = ~15,000 chars**
**Need ElevenLabs Pro ($22/month) or use edge_tts (free)**
